# Security Policy

Falcon Eye is a security tool, so reports are taken seriously.

## Reporting a vulnerability
Please do **not** open a public issue. Open a private report under the
repository's **Security > Report a vulnerability** tab on GitHub, or email
the maintainer (add your contact email here).

Include what you found, how to reproduce it and the affected version. You
will get an answer as soon as possible.

## Scope notes
- Agent keys are shown once and only a SHA-256 hash is stored.
- Known limitations are listed in `docs/LIMITATIONS.md`. Falcon Eye has not
  had an independent security review.


## OWASP alignment and testing

See `docs/OWASP_COMPLIANCE_MATRIX.md` (what is and is not covered) and `docs/SECURITY_TESTING_GUIDE.md` (how to scan). Report vulnerabilities privately as described above.
